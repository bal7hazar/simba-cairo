# TC-S — simba-cairo toolchain bump: Scarb 2.20.1, starknet-foundry 0.64.0

Lot of the nalgebra track of Slingfall (orchestrator: herdr project `slingfall-nalgebra`), 2026-10-02.
Branch `chore/tc-toolchain-bump`. First lot of the TC row of nalgebra-cairo's `docs/PLAN.md`;
nalgebra-cairo's lot (TC-N) follows once this one is merged.

## 1. Goal, context, files to read first

**Goal.** Move simba-cairo from Scarb 2.19.4 / starknet-foundry 0.61.0 to **Scarb 2.20.1 /
starknet-foundry 0.64.0**, with the gas snapshot and the Consumer cost re-measured and the results
shown unchanged.

**Context.** Owner's rule D-180 (2026-10-01): every repository migrates to the latest Scarb,
libraries before the game; **no release comes with the bump** (the version stays 0.2.0, nothing
is published). A compile drift's minimal case is run on the latest Scarb before any upstream issue.
A toolchain bump is its own PR: nothing else ships in it.

**The Cairo compiler is not deterministic on several threads** (measured by Grim World on this VPS,
Scarb 2.19.4 and 2.20.1: clean builds with the default threads gave distinct Sierra files; with
`RAYON_NUM_THREADS=1`, identical). So every measurement, every snapshot regeneration and every
build whose Sierra or CASM is hashed or sized runs with `RAYON_NUM_THREADS=1` exported, on 2.19.4
as on 2.20.1.

Read first: `AGENTS.md` (rules, definition of done), `docs/DESIGN.md`, `scripts/check.sh`,
`scripts/gas_report.py` and `scripts/consumer_cost.py` (docstrings), `consumer_cost.toml`,
`.github/workflows/ci.yml`, `.github/PULL_REQUEST_TEMPLATE.md`.

## 4. Numeric targets

No optimisation. Measured **before** (2.19.4 / 0.61.0 at `origin/main`, in this worktree, before any
pin moves) and **after** (2.20.1 / 0.64.0), all with `RAYON_NUM_THREADS=1`:

1. Sierra gas of every `snforge` test (`gas_report.py`): count of changed entries, the largest moves.
   **Target: zero change.** A change is not a failure by itself, but it is reported with the full
   before / after table, and every `bench_real_<op>__generic` must still equal its direct `fixed`
   call (the zero-cost rule of `AGENTS.md`): if one no longer does, stop and escalate.
2. Consumer cost (`scripts/consumer_cost.py`): library lines, marginal seconds / GB, the closure
   `simba_with_fixed`, before (the CI run of `origin/main`'s last commit, artifact `consumer-cost`)
   and after (this PR's CI run), against the gates of `consumer_cost.toml`.
3. Sierra and CASM size of the `simba` artifacts (SHA-256 and byte size), before / after.
